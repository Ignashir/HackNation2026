HackNation AED demo

The demo runs on a laptop. Your device must be on the same Wi-Fi as the laptop (not mobile data, no VPN).

Laptop address

The laptop prints it when the demo starts (./laptop.sh). It changes when the laptop joins another network.

Enter an IPv4 address like 10.250.162.60.

1. Trust the laptop's certificate (once per device)

Without this, browsers show security warnings and the portal pages stay empty.

Download certificateplain http, works before it is trusted
iPhone / iPad
  1. Open the button above in Safari and tap Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on Caddy Local Authority.
Android
  1. Download the certificate with the button above.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
Mac / Windows
  1. Mac: open the downloaded file, add it to System in Keychain Access, double-click it and set Always Trust.
  2. Windows: open the file → Install Certificate → Local Machine → Trusted Root Certification Authorities.
  3. Restart the browser.
